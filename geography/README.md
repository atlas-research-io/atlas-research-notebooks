# Geography

Visualizations of geographic data, world statistics, and historical exploration routes.

## Notebooks

| # | Title | Description | Key Libraries | Data Source |
|---|-------|-------------|---------------|-------------|
| 001 | [World Geography Stats](001_world_geography.py) | Interactive exploration of Earth's geographic features and climate extremes | pandas, matplotlib, seaborn | CIA World Factbook |
| 002 | [Magellan's Circumnavigation](002_megallan.py) | Animated globe tracing the first circumnavigation (1519-1522) with multi-format export | matplotlib, cartopy | Historical data, Natural Earth |

## Prerequisites

- No API keys required
- Notebook 002 downloads coastline data from Natural Earth (internet required) with built-in fallback
