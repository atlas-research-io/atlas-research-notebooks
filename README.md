# Atlas Research pieces

Open-source intelligence, from geopolitics to your portfolio.

Every piece we publish at [atlas-research.io](https://atlas-research.io) ships with the notebook that made it. Each one pulls its own data from public sources, runs the analysis and renders the charts and animation, so you can check every number yourself.

| 29 Oct 2026 | [Israel voted. Nobody won. The bettors had it first.](https://atlas-research.io/p/007849fe-6257-482f-9263-c8689ed03767) | [notebook](pieces/2026-10-29-israel-voted-nobody-won.py) |

## Run one

The notebooks are [marimo](https://marimo.io) files. Rendering the animations needs `ffmpeg` on your path.

```bash
pip install -r requirements.txt
marimo edit pieces/2026-10-29-israel-voted-nobody-won.py
```
